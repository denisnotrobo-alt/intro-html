Texto importante

Elemento em

Texto enfatizado

O elemento em(emphasis) serve para dar ênfase a um texto

Eu realmente gostei do filme

Eu até que acho as Giovanas legais

Esse trecho está em itálico

O elemento i tem o mesmo comportamento do elemento em. Porém, essa tag serve apenas para aplicar o efeito/estilo Itálico na palavra marcada. Não possui valor semântico, APENAS ESTILO VISUAL.

Elemento mark

Esse texto está marcado

O elemento mark serve parar marcar um trecho de texto como destacado, relevante.

Exemplo de aplicação:

O HTML é muito importante para a web.

Elementos para citações

Elemento cite

Senhor dos Anéis

Esse elemento serve para indicar a fote de um citação ou o título de uma obra.

Exemplo:

Como disse Albert Einstein, A imaginação é mais importante que o conhecimento.

Elemento q

Esse elemento q(quote/citar) serve para marcar citações CURTAS dentro de um texto

Elemento blockquote

O elemento blockquote(bloco de citação longa) serve para indicar um citação em bloco, ou seja, um trecho de texto que foi retirado de outra fonte.

Exemplo:
Nem todos os que vagueiam estão perdidos. O senhor dos anéis
