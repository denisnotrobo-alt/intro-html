Entendendo as listas do HTML

As listas no HTML, servem pra organizar informações relacionadas de forma estruturada e semântica.

As listas são compostas por elementos chamados de LI.

Os LI (list Item/Item da lista). As listas Não possuem limite de itens.

Ordered List - OL

O elemento OL serve para criarmos uma lista ordenada, ou seja, com ordem, importância.

Normalmente aparece numerada

Lista de compras

  1. Banana
  2. Maçã
  3. Laranja
  4. Uva

Unordered List

Serve para criar listas sem ordem específica. Normalmente aparece com bolinhas(bullets)

Exemplo rápido

  • Vou no parque
  • Visitar minha tia
  • Trabalhar

Curiosidade importante

Você pode colocar listas dentro de listas
